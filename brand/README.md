A dog with a cat peeking from behind (concept B). Cutouts are real SVG masks, so the files are
transparent and work on any background.

- `logo-v2-mark-reversed.svg`: sand dog + clay cat, for dark backgrounds (footer → `/logo-mark-reversed.svg`)

To go back to v1: copy `logo-v1-leaf.svg` over `/favicon.svg` and restore the inline leaf SVG in
the header/footer from git history (commit before "Switch to v2 dog + cat logo").
